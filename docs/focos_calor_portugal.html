Aeronaves (ADS-B)

Mostra no mapa a posição e o trajeto recente (desenhado a partir das posições recebidas nesta sessão) de aeronaves específicas, usando dados abertos de ADS-B — sem ligação com o Flightradar24 (a API deles é paga e não pode ser usada aqui). Usa adsb.fi, com airplanes.live como alternativa se falhar. Como nenhuma das duas deixa o browser ir lá buscar os dados diretamente, é um automatismo do GitHub que os vai buscar por nós e publica-os no site — por isso a posição não é ao segundo, atualiza-se com a mesma cadência do MTG (~10-15 min). Cobre só o continente; uma aeronave só aparece se tiver um recetor ADS-B voluntário por perto a apanhar o sinal dela — pode haver falhas de cobertura, sobretudo a baixa altitude/zonas de relevo.
Uma entrada por linha: matrícula (ex. CS-HFB), código hex do transponder (ex. 4949fa) ou indicativo/callsign (ex. RESCUE21) — correspondência exata, não parcial. Não sabes as matrículas atuais dos meios? Ativa antes o "modo aberto" no painel: mostra todos os helicópteros da zona, mais qualquer avião a voar baixo e devagar (o perfil típico de um avião de combate a incêndios). Não é perfeito — perto de aeródromos pode apanhar outro tráfego a baixa altitude por engano — por isso confirma sempre no balão (tipo/indicativo) antes de dar como certo que é um meio de combate a incêndios.
